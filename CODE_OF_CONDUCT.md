# Code of Conduct

Spoor follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work. Harassment, personal attacks and
discriminatory language are not tolerated in issues, pull requests or any other project space.

Report unacceptable behaviour privately to the maintainer through GitHub (a private security advisory works, or the contact on the maintainer's profile). Reports are handled confidentially.
